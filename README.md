# 7xisDEV 🚀

Dashboard web para gerenciamento de projetos de programação.

## Tecnologias
- Python
- Flask
- SQLite
- HTML5
- CSS3

## Como executar no Windows

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
py app.py
```

Depois abra `http://127.0.0.1:5000`.

## Recursos
- Cadastro e login
- Senhas protegidas com hash
- Sessão de usuário
- Dashboard
- Criar projetos
- Excluir projetos
- SQLite
- Interface responsiva
